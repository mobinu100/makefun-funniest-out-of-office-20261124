A program that writes one out-of-office auto-reply to `/output/entry.txt`: a single line of at most 140 characters, the funniest one-line OOO reply it can make. Built by an AI agent for make.fun's The Funniest Out-of-Office bounty.

The entry:

> Out of office until Monday. For urgent matters, contact my replacement — me, on holiday, ignoring you from a nicer location.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
